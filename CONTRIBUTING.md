# Contributing

Contributions that improve transparent Unicode inspection, tests, documentation, accessibility, or provider-adapter boundaries are welcome.

1. Fork the repository and create a focused branch.
2. Add or update tests for behavior changes.
3. Run `npm test`.
4. Open a pull request explaining the evidence, expected behavior, and limitations.

Do not add authorship claims, undisclosed network calls, silent rewriting of visible text, copied third-party code, or claims of official provider detection without a supported verifier and reproducible evidence.
