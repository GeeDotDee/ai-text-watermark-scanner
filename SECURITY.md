# Security policy

Please report suspected vulnerabilities privately to support@aitextwatermark.com with the subject `Security report`.

Include the affected version, reproducible steps, impact, and any suggested mitigation. Do not include private source text, credentials, tokens, payment data, or unrelated personal information.

The project will acknowledge actionable reports and coordinate disclosure after a fix is available. Public issues are appropriate for ordinary bugs that do not expose users or data.
